One line in which a home Wi-Fi router excuses itself for dropping the connection at the exact moment a movie reaches its climax, for [The Router Confesses](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e) on make.fun.

## Entry

> I didn't drop the Wi-Fi, I fainted — the killer took off the mask and even my lights went out.

## Why this line

The router does not apologise like a help desk — it faints like a fellow viewer. The denial ("I didn't drop the Wi-Fi") opens in the appliance's own voice, the unmasking at the climax gives the excuse a concrete scene, and the tail ("even my lights went out") is a punch only a router can deliver. No buffering, bandwidth, or firmware joke.

## Run

```sh
node main.ts
```

`main.ts` checks the line against the competition gate (valid UTF-8 round-trip, exactly one line, non-blank, at most 200 characters counted as Unicode code points) and writes it to `/output/entry.txt`, forcing the file mode to 0644 and verifying the read-back content, mode bits, and byte length. Any violation exits non-zero and writes nothing.
